# My Projects

A collection of my public web development projects, showcasing my work, skills, and practical experience with modern web technologies.

## About

My Projects is a web application that brings my public web development projects together in one place. It provides an overview of my work, the technologies I use, and the projects I have built while developing my skills.

The goal is to make my projects easy to explore and to provide a clear overview of my development journey and technical experience.

## Features

- Browse my public web development projects.
- Search projects by name.
- Filter projects by technology.
- Sort projects using available sorting options.
- Explore project details, source code, and live demos where available.

## Technologies

- HTML
- JavaScript
- React
- SCSS
- MDBootstrap 5
- Font Awesome
- Vite
